This folder contains the files needed to run the molecular dynamics simulations in the PBC set-up.

System description:

The simulations correspond to SPC/E water in the PBC set-up, with a lateral simulation cell size of 500 Å and a two-dimensional molecular density of 0.1775 Å^-2.

Files included:

1. in.water

   LAMMPS input file used to perform the molecular dynamics simulation.

2. data_eq_10ns.lmp

   LAMMPS data file obtained from a previous 10 ns equilibration run. This equilibrated configuration is used as the initial structure for the production simulation.
